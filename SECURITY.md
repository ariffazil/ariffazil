# Security and disclosure

This profile repository is documentation. The software it points to has its own security
policies in each repository (`SECURITY.md` in [arifOS](https://github.com/ariffazil/arifOS),
[A-FORGE](https://github.com/ariffazil/A-FORGE), [AAA](https://github.com/ariffazil/AAA)
and the other federation organs).

**Report a vulnerability:** email arifbfazil@gmail.com with subject `[SECURITY] …`.
Please include reproduction steps. Do not open a public issue for an unpatched vulnerability.

Known gaps and the current security posture of the arifOS kernel are published honestly in
[arifOS/SECURITY.md](https://github.com/ariffazil/arifOS/blob/main/SECURITY.md) — including
what is **not yet proven** (external audit incomplete, ledger head not externally anchored).
